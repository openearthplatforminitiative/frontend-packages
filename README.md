# OpenEPI React-UI

OpenEPI React-UI is an open-source component library built with [Ark-UI](https://ark-ui.com/) and [PandaCSS](https://panda-css.com/). It provides accessible, high-quality components designed to help you build products quickly and efficiently.

## Installation

```
npm install @openepi/react
npm install @pandacss/dev
```

## Development

To begin development, first install and build the packages

```
npm install
npm run build
```

Then you can run storybook to see the results

```
npm run storybook
```

To avoid building the packages every time you do a change, use npm run dev in another terminal

```
npm run dev
```
